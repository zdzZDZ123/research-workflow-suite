# 更新记录

## 0.1.3 · 2026-10-26

用一份真实中文研究报告 DOCX 和一份已发表英文论文 PDF 的副本进行单栏、双栏对照；桌面原文件未变，用户正文仅保存在插件私有工作目录。真实 PDF 的 158 个识别块、9 页文字覆盖差异及 274 处链接要求本地校对，未进入覆盖。DOCX 两版通过自动内容检查，封面视觉问题单独记录，不能等同于投稿版面已经合适。

- PDF 表格网格识别不完整时，保留原表区域图像并要求校对，避免因为缺单元格而让整次预览失败，也不猜测补写数据。
- PDF 内部页跳转不再被误认为脚本/自动动作；链接迁移问题按数量和页面汇总为一个阻断项。脚本、表单和外部动作仍拒绝。
- LibreOffice 检查稿的 PDFium 文字提取偶尔把可见连字符读为未知字形；仅在独立 pypdf 提取能完整读回全部预期字符时解除误报，否则仍阻断。
- 新增真实样稿私有对照页与检查脚本，自动核对本地页面文件、链接和 JavaScript 语法。用户提供的论文不进入发布包。

完整回归为 128 项 Python、12 项 Node，以及隔离 Zotero 中的安装包检查。在线期刊规范和独立模型供应商仍需实际配置后验收。

## 0.1.2 · 2026-10-26

本轮使用同一份合成稿测试六种 Word 版式、三种原生 PDF 重排、扫描件校对，以及 Zotero 本机 APA、IEEE、Vancouver 三种引用样式。12 种候选通过自动检查；扫描件按预期停在本地校对。页面及产物见 [格式矩阵记录](../../docs/VALIDATION.md)。

- 多栏切换时，即使未单独要求“表格适应列宽”，原全页宽表格也会约束到当前栏；嵌套表格及单元格内图片按父单元格可用宽度缩放。不同节的图片分别使用所属节栏宽。
- 参考文献样式在下一个同级或更高级标题处结束，附录正文不再继承参考文献字号。
- “正文 12pt”等仅指定字号的指令不再误认字体。倍数行距与固定行距冲突按来源优先级解析；模板的至少行距保留为待确认。栏间距占尽页面可用宽度时直接拒绝。
- 检查稿校验行距单位、粗斜体、缩进、与下段同页、西文字体，以及页眉页脚文本、页码字段、对齐和字号。规则解析缓存升级，避免沿用旧版错误解析结果。
- 新增本地交互对比页生成器与链接、产物、脚本语法核验；三栏图内字较小的阅读限制如实呈现。

完整验证为 124 项 Python、12 项 Node，以及隔离 Zotero 10.0.6 中 48 项安装包检查。测试材料均为合成稿；在线期刊规范和独立模型供应商尚未配置。

## 0.1.1 · 2026-10-23

本轮改进校对和失败恢复流程，保持正文仅在本机处理及覆盖前完整检查的边界。

- 选择新的期刊指南、修改指令或移除模板后，旧格式预览会失效，转换前重新解析。查看历史任务不再悄悄替换新任务的格式规则。
- 运行时禁用整个操作区的表单输入，避免检查过程中改变参数。保留原本禁用的选项；窗口初始化、关闭和重复打开有独立的并发保护。
- 切换任务会重置批注定位、识别确认和待提交修正稿选择。失败后读取真实任务状态并显示错误，未生成预览也可重新检查。
- 人工 DOCX 修正稿复制为任务内独立快照，支持续接、显式移除和旧版记录迁移。复制期间变更或快照被篡改会阻止继续，历史版本仍保留。
- 高亮、下划线支持同页多区域框选、撤销和清除。原区域与新定位同时显示；无效小框和跨页追加明确提示。后端仍要求框选文字与原批注一致。
- 手动批注定位绑定页面尺寸和渲染图片指纹。重新排版导致页面变化时必须重新定位，包括不能用文字核对的区域和手写批注。
- 恢复逐项隔离错误，重复恢复请求合并执行，与转换共享附件锁。损坏记录有明确诊断，并阻止不确定的新覆盖；可读的未完成任务仍可恢复。
- 提交完成后的阅读器打开失败只显示警告，不触发无效回滚。恢复后刷新失败也不阻断后续任务。

本轮验证记录见 [ACCEPTANCE.md](../../docs/VALIDATION.md)。测试使用合成样稿和隔离文库，未转换实际用户论文。独立模型与 Brave 在线供应商验收仍等待配置。
