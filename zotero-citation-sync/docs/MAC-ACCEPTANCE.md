## 前置准备

使用隔离测试文库与稿件副本。先用 Zotero 官方 Word 插件在 Word 中创建含真实动态引文的基准稿，并记录原文件 SHA-256。文献应是使用者已经核实身份、取得本地材料的真实条目；不得把单元测试中的合成 DOI 导入真实文库。

记录 Mac 硬件及 macOS、Python、Zotero、Word、Zotero Word 插件版本。运行 `python3 -m citation_sync diagnose --output ./mac-diagnostics`。验证启动器、文件选择、Local API、Word Zotero 功能区。点击官方 Add/Edit Citation、Refresh 不应报错。

升级到 0.1.1 后，先在隔离数据目录运行 `python3 scripts/run_tests.py`，保留平台与测试记录，特别检查进程中断恢复和锁竞争。Windows 的这些测试已通过，Mac 的实际锁行为仍需此步骤验证；测试通过也不替代下表的 Word 官方操作。

## 十项核心场景

| 场景 | 操作与验收标准 | Mac 状态 |
| --- | --- | --- |
| 1. DOI 明确新增 | 从 A 的批注请求 B，精确匹配本地条目，原句定位，官方插入后核对字段 | NOT_RUN |
| 2. 同一论文两处引用 | 两个明确原句各插入一处，参考文献保持一条 | NOT_RUN |
| 3. 文首插入重新编号 | IEEE/Vancouver 等编号样式；旧引文编号、文末排序随官方 Refresh 更新 | NOT_RUN |
| 4. 删除引用 | 在独立副本通过官方机制手动删除，再 Refresh 核对书目；当前应用的自动删除未实现，保护检查应拒绝未经实现的删除 | NOT_RUN |
| 5. 文库重复条目 | 相同 DOI 对应两个条目时不自动选定；明确选中实际需要的 item key | NOT_RUN |
| 6. A 与 B 不同 | 检查界面及插入结果确为 B，来源映射仍保留 A 与批注 key/page | NOT_RUN |
| 7. 标题不确定 | 只有相似标题不自动创建或插入；核实身份后再确认 | NOT_RUN |
| 8. 复杂文档 | 使用公式、图片、合并表格、脚注、批注、修订；非目标对象保留，目标段落有修订时阻止自动定位提交 | NOT_RUN |
| 9. 连续两次同步 | 用结果副本再扫描，无重复插入；重新选择旧原稿应提示已有结果 | NOT_RUN |
| 10. 重开可编辑 | 保存关闭再打开，通过 Zotero Add/Edit Citation 编辑新旧引文，再 Refresh；不接受纯文本外观作为证据 | NOT_RUN |

对 APA、IEEE、Vancouver、Nature 分别保存独立副本；在官方 Document Preferences 切换，检查文内与文末一致，并重开验证。应用只记录目标样式、检查实际文档样式元数据，不自行实现 CSL 字段更新。

## 恢复及故障检查

- 勾选前、处理中保存原稿：应停止准备，原稿保留用户最后一次内容。
- 文库中途修改、请求删除或重复点击：应报冲突或阻止重复任务。
- 工作文件被占用、目录只读、磁盘空间不足：应保留原稿，不把失败记录为已同步。
- 强制退出后：保留工作目录与锁，不自动清空。按限制文档处理后核查备份、工作副本和审计是否一致。
- 通过后手动修改副本：历史应提示旧验证失效；复核不能直接返回旧成功结果。
- 恢复应生成独立文件，哈希与备份一致，修改后的工作副本仍存在。

## 实机证据格式

每项记录版本、时间、输入及输出 SHA-256、批注 key、实际引用 B 的 item key、预期原句、官方操作截图/录像、本机操作日志、重开可编辑结果、文末书目核对结论。截图与论文含私有内容，只保存到本地验收目录。

只有上述实际 Mac 验收通过后，才评估自动化官方对话框或其他正式集成。不可通过修改单元测试、勾选模拟确认或改变 `supported_mac()` 来解锁批量写入；本版本没有该功能。
